> 교체 방법: `README.md`의 "개인 스킬에 노트 경로 연결" 섹션 참조.

# Daily Note

## Step 1 — 모드 판별

사용자 입력에서 모드를 결정한다.

| 입력 키워드 | 모드 |
|------------|------|
| "만들어줘", "시작", "오늘 노트" | 아침 모드 — 노트 생성 |
| "채워줘", "로그", "마무리" | 저녁 모드 — 작업 로그 갱신 |

파일 경로: `<개인_노트_경로>/일일노트/YYYY-MM-DD.md`

---

## Step 2-A — 아침 모드: 노트 생성

1. 오늘 날짜 파일이 이미 있으면 "이미 존재합니다" 알리고 열어줌
2. 없으면 아래 순서로 할 일 목록을 수집한다:
   - 현재 디렉토리에 `HANDOFF_NOW.md`가 있으면 §2 다음 작업 항목 읽기
   - 어제 일일노트(`YYYY-MM-DD.md`)가 있으면 "내일로 넘기는 것" 섹션 읽기
   - `<개인_노트_경로>/career/weekly-tasks.md`가 있으면 오늘 날짜(`### M/D` 형태) 헤더 아래의 체크박스 항목 읽기 → "사이드 (Career Roadmap)" 섹션 pre-fill
3. 수집한 항목으로 아래 템플릿을 채워 파일 저장

```markdown
---
tags: [일일노트]
date: YYYY-MM-DD
---

# MM월 DD일 (요일)

## 오늘 할 일

- [ ] <HANDOFF §2 또는 어제 이월 항목>
- [ ] 

## 사이드 (Career Roadmap)

<!-- weekly-tasks.md 오늘 날짜 항목 자동 pre-fill. 없으면 이 섹션 생략 -->
- [ ] <career/weekly-tasks.md 오늘 항목>

## 작업 로그

| 시간 | 내용 | 이슈 |
|------|------|------|
|  |  |  |

## 메모

## 내일로 넘기는 것

- 
```

---

## Step 2-B — 저녁 모드: 작업 로그 갱신

1. 오늘 일일노트 파일을 읽는다
2. 오늘 git 커밋 목록 수집:
   ```bash
   git log --oneline --since="today 00:00" --author="$(git config user.name)" 2>/dev/null || echo "git 없음"
   ```
3. 커밋 목록을 작업 로그 테이블에 채운다 (시간은 커밋 시각, 이슈는 커밋 메시지에서 #번호 추출)
4. 미완료 체크박스 항목을 "내일로 넘기는 것" 섹션에 이동
5. 파일 저장

---

## Step 3 — 완료 보고

```
[일일노트]
파일: 개인/일일노트/YYYY-MM-DD.md
모드: 아침/저녁
- 할 일 N개 pre-fill
- 커밋 N개 작업 로그 반영  ← 저녁 모드만
- 미완료 N개 이월          ← 저녁 모드만
```
