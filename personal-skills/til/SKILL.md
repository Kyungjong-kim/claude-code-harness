> ⚠️ **설치 후 필수**: 이 파일의 `<개인_노트_경로>`를 실제 노트 경로로 교체해야 정상 동작한다.
> 교체 방법: `README.md`의 "개인 스킬에 노트 경로 연결" 섹션 참조.

# TIL (Today I Learned)

## Step 1 — 입력 수집

```bash
# 노트 경로 설정 확인 — 미설정이면 중단
if echo "<개인_노트_경로>" | grep -q '<개인_노트_경로>'; then
  echo "⚠ [설정 필요] ~/.claude/skills/til/SKILL.md 에서 <개인_노트_경로>를 실제 경로로 교체하세요."
  echo "  교체 후 스킬을 다시 실행해주세요. (참조: README.md '개인 스킬에 노트 경로 연결' 섹션)"
  exit 1
fi
```

사용자가 배운 내용을 붙여넣거나 설명하면 아래를 파악한다.

| 항목 | 파악 방법 |
|------|----------|
| 주제 | 내용 핵심 키워드 추출 또는 질문 |
| 날짜 | 오늘 날짜 고정 |

파일 경로: `<개인_노트_경로>/TIL/YYYY-MM-DD_<주제>.md`

기존 TIL 중 연관된 파일이 있으면 링크로 연결한다:
```bash
find <개인_노트_경로>/TIL -name "*.md" | sort -r | head -30
```

---

## Step 2 — 구조화

내용을 아래 템플릿으로 정리한다.

```markdown
---
tags: [TIL]
date: YYYY-MM-DD
---

# TIL — YYYY-MM-DD

## <주제>

**배경**: 어떤 작업 중에 알게 됐는지

**내용**:
<핵심 개념·원리를 간결하게>

**예시 / 코드**:

```<언어>
<코드>
```

**참고**:
- <링크 또는 출처>

---

## 연관 TIL

- [[관련 파일명]] ← 있을 때만
```

---

## Step 3 — TIL 인덱스 갱신

`개인/TIL/README.md`가 있으면 오늘 항목을 최상단에 추가한다.
없으면 새로 생성한다.

```markdown
# TIL 인덱스

| 날짜 | 주제 | 파일 |
|------|------|------|
| YYYY-MM-DD | <주제> | [[YYYY-MM-DD_주제]] |
...
```

---

## Step 4 — 완료 보고

```
[TIL]
파일: 개인/TIL/YYYY-MM-DD_<주제>.md
연관 TIL: N개 링크
인덱스: 갱신 완료
```
