> 교체 방법: `README.md`의 "개인 스킬에 노트 경로 연결" 섹션 참조.

# Meeting Note

## Step 1 — 입력 수집

사용자가 회의 내용을 붙여넣으면 아래 정보를 파악한다.
없는 항목은 사용자에게 질문한다.

| 항목 | 파악 방법 |
|------|----------|
| 회의 제목 | 내용에서 추출 또는 질문 |
| 날짜 | 오늘 날짜 기본값 |
| 참석자 | 내용에서 추출 (멘션·이름) |

파일 경로: `<개인_노트_경로>/개인/회의노트/YYYY-MM-DD_<제목>.md`

---

## Step 2 — 구조화

원문을 아래 4개 섹션으로 분류한다.

- **논의 내용**: 의견 교환, 현황 공유, 문제 제기
- **결정 사항**: 합의되거나 확정된 내용
- **액션아이템**: 담당자·내용·기한이 있는 할 일 → 테이블로 정리
- **참고 링크**: URL, 이슈 번호, 문서 링크

```markdown
---
tags: [회의]
date: YYYY-MM-DD
---

# <제목>

**일시**: YYYY-MM-DD  
**참석자**: <이름 목록>  
**목적**: <회의 목적 한줄>

---

## 논의 내용

- 

## 결정 사항

- 

## 액션아이템

| 담당 | 내용 | 기한 |
|------|------|------|
|  |  |  |

## 참고 링크

- 
```

---

## Step 3 — GitHub 이슈 변환 (선택)

파일 저장 후 아래 질문을 한다:

> "액션아이템 중 GitHub 이슈로 만들 항목이 있나요? (있으면 번호 또는 내용 지정)"

있다고 하면 `/<프로젝트>-github-issue` 스킬로 연계한다.

---

## Step 4 — 완료 보고

```
[회의노트]
파일: 개인/회의노트/YYYY-MM-DD_<제목>.md
- 논의 N개 / 결정 N개 / 액션아이템 N개
```
