# 월초 HANDOFF 아카이브 절차

월초에 전월 Session Update 전체를 `HANDOFF_archive_YYYY.md`로 이관하는 절차.

---

## 언제 수행하는가

- 매월 1일 (또는 월초 첫 세션 시작 시)
- `HANDOFF.md`에 전월 Session Update 항목이 쌓여 있을 때

---

## 수행 절차

### 1단계 — 아카이브 파일 확인

```bash
BASE="docs/<서비스명>"   # 또는 <패키지경로>/docs
YEAR=$(date +%Y)
ARCHIVE="$BASE/plans/HANDOFF_archive_${YEAR}.md"

ls "$ARCHIVE" 2>/dev/null && echo "기존 아카이브 존재" || echo "신규 생성 필요"
```

### 2단계 — 전월 Session Update 추출

```bash
LAST_MONTH=$(date -v-1m +%Y-%m 2>/dev/null || date -d "last month" +%Y-%m)
echo "이관 대상 월: $LAST_MONTH"

# HANDOFF.md에서 전월 Session Update 섹션 확인
grep -n "## Session Update ${LAST_MONTH}" "$BASE/plans/HANDOFF.md" | head -5
```

### 3단계 — 이관 bash 스크립트

아래 스크립트로 전월 Session Update 블록을 추출해 아카이브 파일 앞에 prepend한다.

```bash
#!/bin/bash
# 월초 HANDOFF 아카이브 스크립트

BASE="docs/<서비스명>"   # ← 실제 경로로 교체
YEAR=$(date +%Y)
LAST_MONTH=$(date -v-1m +%Y-%m 2>/dev/null || date -d "last month" +%Y-%m)
HANDOFF="$BASE/plans/HANDOFF.md"
ARCHIVE="$BASE/plans/HANDOFF_archive_${YEAR}.md"

# 전월 섹션 추출 (## Session Update YYYY-MM 으로 시작하는 블록 전체)
EXTRACTED=$(awk "/^## Session Update ${LAST_MONTH}/{found=1} found{print} /^## Session Update [0-9]{4}-[0-9]{2}/{if(found && !/^## Session Update ${LAST_MONTH}/){found=0}}" "$HANDOFF")

if [ -z "$EXTRACTED" ]; then
  echo "⚠ 이관할 ${LAST_MONTH} Session Update 항목이 없습니다."
  exit 0
fi

# 아카이브 파일 앞에 prepend
if [ -f "$ARCHIVE" ]; then
  TEMP=$(mktemp)
  echo "$EXTRACTED" > "$TEMP"
  echo "" >> "$TEMP"
  cat "$ARCHIVE" >> "$TEMP"
  mv "$TEMP" "$ARCHIVE"
else
  echo "# HANDOFF Archive ${YEAR}" > "$ARCHIVE"
  echo "" >> "$ARCHIVE"
  echo "$EXTRACTED" >> "$ARCHIVE"
fi

echo "✓ ${LAST_MONTH} Session Update → $ARCHIVE 이관 완료"

# HANDOFF.md에서 이관된 섹션 제거 (선택 — 수동 확인 후 제거 권장)
echo ""
echo "다음 명령으로 HANDOFF.md에서 전월 항목을 제거할 수 있습니다:"
echo "  (직접 편집 권장 — 자동 삭제 시 실수 위험)"
```

### 4단계 — 검증

```bash
# 아카이브에 이관됐는지 확인
head -20 "$ARCHIVE"

# HANDOFF.md에서 전월 항목 제거 여부 확인
grep "## Session Update ${LAST_MONTH}" "$HANDOFF" | wc -l
```

### 5단계 — HANDOFF.md 정리

아카이브 확인 후 HANDOFF.md에서 전월 Session Update 블록을 수동으로 제거한다.

---

## 주의 사항

- **수동 확인 필수**: 자동 삭제보다 눈으로 확인 후 제거하는 것을 권장
- **아카이브 파일 규칙**: `HANDOFF_archive_YYYY.md` — 연도별 1파일로 관리
- **이관 범위**: 전월(지난달) 전체. 당월 Session Update는 이관하지 않음
- **HANDOFF_NOW.md는 건드리지 않음**: HANDOFF_NOW.md는 현재 상태 파일이므로 아카이브 대상 아님

---

## 자동화 (선택)

Claude Code `/session-close` 스킬에 월초 감지 로직을 추가해 자동으로 아카이브를 트리거할 수 있다.
현재는 사용자가 월초에 수동으로 이 절차를 실행한다.
