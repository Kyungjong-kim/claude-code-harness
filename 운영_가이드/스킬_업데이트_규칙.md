# 스킬 업데이트 규칙

스킬을 수정할 때 **하네스 소스 폴더와 `~/.claude/skills/` 양쪽을 함께 갱신**한다.

```bash
# 로컬에서 수정 후 하네스 폴더로 동기화 (프로젝트 스킬)
cp ~/.claude/skills/<스킬명>/SKILL.md \
   <하네스폴더>/skills/<스킬명>/SKILL.md

# 개인 생산성 스킬인 경우
cp ~/.claude/skills/<스킬명>/SKILL.md \
   <하네스폴더>/personal-skills/<스킬명>/SKILL.md
```

| 위치 | 역할 |
|------|------|
| `하네스/skills/` | 프로젝트 스킬 소스 오브 트루스 |
| `하네스/personal-skills/` | 개인 스킬 소스 오브 트루스 |
| `~/.claude/skills/` | 실행 위치 — Claude Code가 실제로 읽는 곳 |

## 주의사항

- **두 위치 모두 갱신**: 한쪽만 수정 시 배포·재설치에서 불일치 발생
- **개인 스킬 노트 경로**: SKILL.md 안에 `<개인_노트_경로>` placeholder가 있으면 하네스 소스에는 placeholder 형태 유지, `~/.claude/skills/`에는 실제 경로로 치환된 상태 유지 (install.sh가 자동 치환)
- **버전 표기**: SKILL.md frontmatter `updated:` 날짜를 갱신해 동기화 시점 추적
