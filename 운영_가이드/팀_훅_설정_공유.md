# 팀 훅 설정 공유 가이드

훅 스크립트(`check-source-doc.sh`, `pre-commit-doc-check.sh`)는 `--hooks`로 전역 설치되므로
팀원마다 경로 설정이 달라질 수 있다.
이 문서는 팀 전체가 동일한 경로 설정을 사용하도록 공유하는 방법을 설명한다.

> **신규 프로젝트라면**: `/project-init` 실행 시 Phase 1-B 소스 경로 분석 결과로
> `.claude/hooks-config.sh`를 자동 생성한다. 이 가이드를 수동으로 따를 필요 없다.
> 기존 프로젝트에 사후 적용할 때 이 문서를 참조한다.

---

## 문제

- 훅 스크립트는 `~/.claude/hooks/` (전역)에 설치 — git 추적 불가
- 각 팀원이 `[프로젝트 설정]` 구간을 독립적으로 수정 → 설정이 제각각이 될 수 있음
- 팀원 A와 B가 다른 소스 경로 패턴을 사용하면 FE_*/BE_*.md 체크 결과가 달라짐

---

## 해결 방법 — 공유 설정 파일 추출

프로젝트 레포 안에 훅 경로 설정만 별도 파일로 추출해 팀이 공유한다.

### 1단계: 프로젝트 레포에 공유 설정 파일 생성

```bash
mkdir -p .claude
```

`.claude/hooks-config.sh` 파일을 생성하고 아래 내용을 채운다:

```bash
# .claude/hooks-config.sh
# 이 파일은 git 추적 대상 — 팀 전체가 동일한 훅 경로 설정을 공유한다.
# 실제 경로로 교체 후 커밋.

# ── FE 소스 경로 (check-source-doc.sh if 블록) ───────────────
FE_PATTERN="<서비스명>/src/(pages|components|hooks|api)/([^/]+)/"
FE_DOC_BASE="docs/<서비스명>/pages"
FE_PROJECT="<서비스명>"

# ── BE 소스 경로 (check-source-doc.sh elif 블록) ────────────
BE_PATTERN="<BE소스경로>/(routes|services|handlers|models)/([^/]+)"
BE_DOC_BASE="docs/<BE서비스명>/pages"
BE_PROJECT="<BE서비스명>"

# ── pre-commit-doc-check.sh 경로 ───────────────────────────
FE_COMMIT_PATTERN="^(<소스경로1>|<소스경로2>)/.*\.(js|ts|tsx|jsx)$"
BE_COMMIT_PATTERN="^(<BE소스경로>)/.*\.(py|go|java|kt|rs)$"
FE_DOMAIN_EXTRACT='s|<소스경로>/pages/([^/]+)/.*|\1|'
BE_DOMAIN_EXTRACT='s|<BE소스경로>/routes/([^/]+)/.*|\1|; s|<BE소스경로>/services/([^/]+)/.*|\1|; ...'
FE_DOC_DIR_BASE="docs/<서비스명>/pages"
BE_DOC_DIR_BASE="docs/<BE서비스명>/pages"

# ── 보호 브랜치 (선택, 기본값: develop|main|master) ─────────
# 팀 컨벤션이 다르면 customize. 예: dev만 사용하거나 release/* 차단
# BLOCKED_BRANCHES="dev|main|release/.*"
```

### 2단계: git 추적 + 커밋

```bash
git add .claude/hooks-config.sh
git commit -m "docs: [공통] 팀 훅 경로 설정 공유 파일 추가"
```

팀원은 `git pull` 후 자동으로 동일한 설정을 받는다.

> **훅 스크립트는 `.claude/hooks-config.sh`를 자동으로 소싱한다.**
> 팀 리드가 Step 1에서 `hooks-config.sh`를 생성·커밋하면 추가 수정 없이 팀 전체에 적용된다.

---

## 팀원 온보딩 절차

새 팀원이 합류했을 때:

```bash
# 1. 하네스 스킬·훅 설치
bash 하네스/install.sh --hooks

# 2. 레포 클론 (공유 설정 파일 자동 포함)
git clone <레포URL>
cd <레포>

# 완료 — 훅이 .claude/hooks-config.sh를 자동 소싱하므로 추가 설정 불필요
```

---

## 주의 사항

- `hooks-config.sh`는 bash 변수 정의만 포함해야 한다 (실행 명령 금지)
- 경로 변경 시 `hooks-config.sh`만 수정·커밋하면 전원 적용됨
- 다중 프로젝트 사용 시: `git rev-parse --show-toplevel`로 현재 레포를 자동 감지하므로 프로젝트별 설정이 자동으로 분리됨
